About Customer Feedback Intelligence

Architecture, methodology, and technical specifications.

🎯 Problem Statement

E-commerce businesses receive thousands of customer reviews daily. Reading reviews manually is slow, while simple overall star ratings fail to reveal why customers are dissatisfied. For example, a customer might love a food product's taste but hate its damaged packaging.

⚙️ Technical Solution Stack
    Python 3.11 - Core ML & NLP execution environment TF-IDF Vectorizer - 1–2 n-grams, 20,000 maximum vocabulary features Logistic Regression - Deployment model (Accuracy: 88.12%, Macro F1: 67.04%) ABSA Engine - Rule-based aspect & clause matching for 7 domain categories Flask API - Python REST backend serving ML prediction endpoints HTML5 / Custom CSS / Vanilla JS - Responsive SaaS single page application
🏷️ Dataset & Label Methodology

Trained on the Amazon Fine Food Reviews dataset (568,454 original reviews, 393,579 clean deduplicated reviews).

Proxy Label Definition:
• 1–2 Stars ➔ Negative
• 3 Stars ➔ Neutral
• 4–5 Stars ➔ Positive

Note: These proxy labels are derived from star ratings and serve as practical targets for machine learning.
